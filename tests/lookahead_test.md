# 后视镜（前视偏差）反事实检验 · 结论

> 检验脚本：`tests/lookahead_test.py`
> 检验目的：定量确认本回测系统**没有用未来数据预测过去**（look-ahead bias），
> 即"今天做决策时不会用到明天才公告的财报/行情"。

## 一、一句话结论

**本策略没有开后视镜，没有用明天的数据预测今天。** 业绩数字是保守的、可信的。

反事实检验显示：人为偷看未来一整年财报后，三档年化收益暴涨 8~30 个百分点/年，
而干净版远低于此。如果系统真存在前视泄漏，作弊版与干净版的差距不会如此悬殊——
未来数据"完全没被使用"是这件事最直接的证据。

## 二、检验方法

1. **注入前视**：子类 `DataStore` 重写 `facts_asof`，把每个调仓日的财务可见截止日
   从 `announce_date <= asof` 偷改成 `announce_date <= asof + 365 天`，
   等于让系统在 2017-05-15 就知道 2018 年才公告的年报/中报/季报。
2. **绕过筛选缓存**：磁盘缓存 key 只含 `asof + 数据 mtime + rules 指纹`、**不含数据内容**，
   不拦截会命中干净版旧结果、测试作废。通过 monkeypatch `screen_cache.get_screen`
   强制重算注入版截面。
3. **同进程 apples-to-apples**：先跑干净版（走磁盘缓存取基线）→ 清 `_SCREEN_CACHE`
   → 再跑注入版，三档（30只 / Top5 / Top3）逐项对比。

## 三、结果（决定性）

| 档位 | 干净版年化 | 偷看未来版年化 | 年化差距 | 超额(对等权)跳升 |
|---|---|---|---|---|
| 默认30只 | +15.99% | **+24.39%** | +8.4pp | +8.6pp |
| Top5 | +15.33% | **+29.67%** | +14.3pp | +14.5pp |
| Top3 | +11.66% | **+41.24%** | +29.6pp | +29.8pp |

规律符合直觉：**越集中的组合，越放大"提前知道哪只盈利要爆"的价值**——
Top3 偷看未来后年化直接冲到 41%，是干净版的 3.5 倍。

## 四、判读

如果系统真使用了未来数据，业绩应当接近上表的红色数值（作弊版）；
而干净版比作弊版低 8~30 个百分点/年，且任何有意义的前视泄漏都会在这个检验里炸出来——
它没炸。因此：

- **无数值前视**：财报按公告日过滤、行情取调仓日收盘、z 分数用当日截面、宇宙含退市股防幸存者偏差，
  四道防线真实落地，不是空话。
- **业绩是被低估的**：干净版在"看不见未来"的约束下仍跑出上述数字，比作弊版保守。

## 五、需诚实保留的两项（不是前视，但影响口径）

1. **t+0 执行**：信号与成交都用调仓日收盘，未实现 t+1 次日开盘，略偏乐观。
2. **基准端轻微幸存者偏差（对策略不利）**：等权基准对 d→d_next 间退市的股票因下期无价被 drop，
   等于把退市暴跌从基准里剔掉 → 基准被抬高 → 策略超额被压低，方向保守。

两项都让当前业绩"更不好看"，不构成业绩虚高。
