## 二、发现的问题

### 🔴 P0：幸存者偏差 —— 回测结论偏乐观，影响所有结论的可信度

- 宇宙取自 **2026 年**的沪深300 / 中证500 成份股快照（800 只），回测 2018 年时点
  → 等于**预知了哪些股票后来能留在/进入指数**。
- 宇宙里虽注入了 5 只标注退市的股票，但**有行情的 298 只中，退市股占 0 只**
  （腾讯接口不提供退市股行情）→ 回测宇宙实际不含任何后来退市/爆雷的公司。
- **影响**：策略回测结果（年化 11.16%、超额 -2.91%）是**偏乐观**的。
  真实环境下，把退市股与掉出指数的股票纳入后，收益只会更低、超额只会更难看。
- 建议：如需严谨结论，应改用**历史时点的指数成份股**（point-in-time universe），
  或至少在报告中把这个偏误方向和量级写清楚。

### 🟠 P1：两条排雷规则形同虚设（失效却不报错）

排雷层共 7 类规则，实际只有 5 类能触发：

| 规则 | 字段有效率 | 失效原因 |
|---|---|---|
| `pledge_ratio`（质押率） | **0.0%** | 库中有 393 条，但 `announce_date` 全是 2026-09-04 —— 接口只给**当前快照**，历史时点取不到 |
| `goodwill_to_equity`（商誉） | **0.0%** | 接口**根本不提供商誉字段**，规则永久失效 |
| 其余 5 类 | 84%~100% | 正常 |

`pledge_ratio` 还额外暴露一个已修的代码 bug：质押数据的 `period` 是时间戳
（`202609040101`）而非年报格式（`1231` 结尾），会被 `_metrics_for_code` 的年报过滤
整批丢弃。已在 `metrics.py` 修复为"回退取最新快照"——但受数据源限制，
历史回测中仍然取不到。**这类"规则静默失效"很危险：使用者会以为有这条防线。**

### 🟡 P2：流程与工具问题

- 参数敏感性检验首次用 `nohup` 挂后台**未启动成功**（日志 0 字节、进程已退出），
  第二次前台执行才跑通。后台任务的启动方式需要确认。

## 三、参数敏感性检验（回测纪律要求）

| 参数 | 扰动 | 年化收益 |
|---|---|---|
| baseline | — | 11.16% |
| `factors.weights.value` | +20% / -20% | 10.90% / 10.28% |
| `factors.weights.quality` | +20% / -20% | 10.66% / 11.36% |
| `factors.percentile_floor` | +20% / -20% | 11.20% / 11.95% |

**判据**：扰动后年化收益发生质变（如由正转负）= 过拟合。
**结果**：全部落在 10.28%~11.95%，无质变 → **未过拟合，参数稳健**。
（代价是：它是**稳健地跑输**基准，而不是偶然跑输。）

## 四、测试结论

**可以放心的部分**：防前视偏差的地基正确；调仓日、边界条件、组合风控约束均正确；
参数不过拟合；排雷层对"纸面利润 + 财务操纵"型爆雷有真实识别力
（7 只历史爆雷股中 4 只爆雷前被拦下）。

**不能放心的部分**：

1. **回测收益数字不可直接采信** —— 幸存者偏差使其偏乐观，真实超额只会比 -2.91% 更差。
2. **排雷层实际只有 5 条规则在起作用** —— 质押与商誉两条恒失效，且系统不提示。
3. **基准选择存疑** —— 用的是等权宇宙（A 股等权含小盘/反转溢价，本身难超越），
   设计文档指定的中证红利质量 / 红利低波基准尚未接入。

**建议的下一步**（按优先级）：

1. 改用历史时点指数成份股，或在报告中显式标注幸存者偏差的方向与量级 ← 最高优先级
2. 让排雷层在"规则所需字段缺失"时**显式告警**，而不是静默跳过
3. 接入真实基准（中证红利质量 / 红利低波），重跑超额结论
